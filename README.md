# 🌐 Browser History Simulator

A C-based project that simulates browser history and navigation, demonstrating fundamental programming concepts and data structures.

The project aims to replicate basic browser navigation behavior through a simple, menu-driven interface.

## ✨ Features

- 🌍 **Page Navigation** — Simulate visiting webpages.
- ⬅️ **Back Navigation** — Navigate to previously visited pages.
- ➡️ **Forward Navigation** — Move forward through browsing history.
- 📚 **History Management** — Manage previously visited pages.
- 📁 **File Handling** — Explore file operations for storing and managing data.

*Note: The listed features should match the operations implemented in your source code.*

## 🛠️ Tech Stack

- **Programming Language:** C
- **Core Concepts:** Data Structures, Pointers, and Memory Management
- **File Handling:** C File I/O
- **Development Environment:** Visual Studio Code

## 🚀 Getting Started

### Prerequisites

- GCC compiler or another compatible C compiler
- Git (optional, for cloning the repository)

### Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/browser-history-simulator.git
```

**2. Navigate to the project directory**

```bash
cd browser-history-simulator
```

**3. Compile the program**

```bash
gcc browser.c -o browser
```

**4. Run the program**

On Windows PowerShell:

```powershell
.\browser.exe
```

On Linux/macOS:

```bash
./browser
```
